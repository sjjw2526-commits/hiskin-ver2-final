## 파일 규격 (중요)

원본 촬영본을 그대로 넣으면 로딩이 매우 느려집니다. 아래 기준으로 변환 후 넣어주세요.

- **가로 폭 2560px 이하** (레티나 대응 상한. 그 이상은 화질 차이 없이 용량만 늘어남)
- **JPEG 품질 82** 내외 → 장당 **200~400KB**
- **PNG 금지** (사진은 PNG로 저장하면 10~100배 무거워집니다. 로고·아이콘만 PNG)

변환이 번거로우면 원본 파일 위치만 알려주시면 제가 변환해서 넣어드립니다.

| cert_patent.jpg | 1500×2121 | ✅ 항산화·항염 조성물 특허 (특허청 / 제10-2533040호) |
| cert_rnd_lab.jpg | 1500×2121 | ✅ 기업부설연구소 인정서 (과기정통부·KOITA / 제2021111420호) |
| cert_irdop_analysis.jpg | 1500×2121 | ✅ IRDOP 성분 분석 성적서 (VILAS 997) |

5장 모두 **A4(1:1.414) 흰 여백으로 패딩**되어 타일이 똑같이 채워집니다.
원본은 비율이 제각각(1.33~1.49)이었고 ISO 인증서는 90° 회전된 상태였습니다.

교체하려면 원본을 주시고 `node scripts/build-certs.mjs` 를 돌리면 됩니다
(스크립트 상단 `JOBS` 의 경로만 바꾸면 됩니다).
