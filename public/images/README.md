## 파일 규격 (중요)

원본 촬영본을 그대로 넣으면 로딩이 매우 느려집니다. 아래 기준으로 변환 후 넣어주세요.

- **가로 폭 2560px 이하** (레티나 대응 상한. 그 이상은 화질 차이 없이 용량만 늘어남)
- **JPEG 품질 82** 내외 → 장당 **200~400KB**
- **PNG 금지** (사진은 PNG로 저장하면 10~100배 무거워집니다. 로고·아이콘만 PNG)

변환이 번거로우면 원본 파일 위치만 알려주시면 제가 변환해서 넣어드립니다.

### 영상은 그냥 넣지 마시고 변환해주세요

```bash
npm run video -- "C:/Users/kryst/Downloads/동영상 1.mp4" 2 3.7
```
- 두번째 숫자 = 슬롯 번호 → `public/videos/review-02.mp4`
- 세번째 숫자 = **썸네일로 쓸 시각(초)** → `public/videos/review-02.jpg` (생략하면 1초)

썸네일 시각은 눈으로 골라야 합니다. 눈 감은 프레임이 은근히 자주 걸립니다.
뽑고 나면 `VideoGrid.tsx` 의 해당 항목에 `poster: "/videos/review-02.jpg"` 를 넣어주세요.

폰 영상을 그대로 넣으면 안 되는 이유가 둘 있습니다.

1. **아이폰은 H.265(HEVC)로 저장합니다.** 크롬·파이어폭스에서 재생이 안 되고
   카드가 조용히 자리표시로 바뀝니다. → H.264로 다시 인코딩합니다.
2. **요즘 폰 영상은 HDR(HLG)입니다.** 그대로 변환하면 일반 모니터에서
   색이 바래고 밋밋해집니다. → BT.709 SDR로 톤매핑합니다.

변환 결과는 810×1440 / 편당 2~4MB 입니다. 카드가 화면에서 제일 클 때가 384px라
1080으로 넣어도 용량만 두 배가 되고 보이는 차이는 없습니다.

개수를 늘리거나 줄이려면 `src/components/VideoGrid.tsx`의 `REVIEWS` 배열만 수정하면 됩니다.
**계정명(handle)과 문구도 배열에서 같이 바꿔야 합니다** — 현재 review-02 외에는 전부 자리표시입니다.

5장 모두 **A4(1:1.414) 흰 여백으로 패딩**되어 타일이 똑같이 채워집니다.
원본은 비율이 제각각(1.33~1.49)이었고 ISO 인증서는 90° 회전된 상태였습니다.

교체하려면 원본을 주시고 `node scripts/build-certs.mjs` 를 돌리면 됩니다
(스크립트 상단 `JOBS` 의 경로만 바꾸면 됩니다).
